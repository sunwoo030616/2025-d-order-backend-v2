# 🍻 D-Order V2

> 대학 축제 주점 통합 운영 플랫폼 (Version 2)

관리자 기능과 서비스 안정성을 강화한 두 번째 버전입니다.

## 🔄 Project Evolution

D-Order는 실제 운영 경험을 바탕으로 지속적으로 발전한 프로젝트입니다.

- **V1** : 서비스 최초 개발 및 운영 (8 Booths · 1,200+ Users)
- **V2** : 사용자 피드백 반영 및 운영 안정화 (10 Booths · 1,800+ Users)
- **V3** : 시스템 고도화 및 서비스 확장 (23 Booths · 2,500+ Users)
